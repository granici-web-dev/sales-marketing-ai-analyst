## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | Tenant data leak via missing filter | mitigate | `with_loader_criteria(TenantScopedMixin, ...)` on ALL selects; D-06 test (Plan 01) proves enforcement; TenantIsolationError raised when context is None |
| T-04-02 | Tampering | Seed admin password hardcoded in migration | mitigate | Password stored as bcrypt hash (`$2b$12$...`), not plaintext; bcrypt work factor 12; admin must change password after first login (Phase 6+) |
| T-04-03 | Tampering | with_loader_criteria applied to Tenant model | mitigate | `TenantScopedMixin` used (not `Base`) — Tenant model inherits only Base+TimestampMixin; no tenant_id on Tenant table prevents AttributeError |
| T-04-04 | Information Disclosure | Alembic URL in alembic.ini | mitigate | URL read from DATABASE_URL env var at runtime via `config.set_main_option`; no credentials in alembic.ini |
| T-04-05 | Elevation of Privilege | SQLAlchemy relationship loads bypassing tenant filter | mitigate | `include_aliases=True` in with_loader_criteria ensures joined-load aliases also carry the filter |
