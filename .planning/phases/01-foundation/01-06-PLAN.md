<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → POST /auth/login | Untrusted email+password input crosses here |
| refresh_token cookie → POST /auth/refresh | Cookie sent automatically by browser; must be HttpOnly |
| access_token cookie → proxy.ts JWT verify | Frontend reads access_token from cookie set by frontend JS after login |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Spoofing | JWT algorithm confusion at login | mitigate | create_access_token calls jwt.encode with explicit algorithm=settings.jwt_algorithm ("HS256"); verify_token calls jwt.decode with algorithms=["HS256"] list — never None |
| T-06-02 | Spoofing | Stale JWT after logout | mitigate | Access token TTL = 15 minutes; refresh endpoint rotates cookie on every call; logout deletes cookie; no server-side token blocklist needed for 15-min window |
| T-06-03 | Spoofing | Refresh token theft via XSS | mitigate | refresh_token cookie is HttpOnly (JS cannot read it); path scoped to /api/v1/auth/refresh (cookie not sent to other endpoints) |
| T-06-04 | Information Disclosure | PII in auth logs | mitigate | auth.py logs user_id only — `logger.info("user_logged_in", user_id=str(user.id))`; auth_service.py logs `logger.info("login_attempt")` with no fields; email and password are never logged |
| T-06-05 | Elevation of Privilege | CVE-2025-29927 Next.js middleware bypass | mitigate | Using Next.js 16.2 (patched); backend also validates on every API call via Depends(get_session) which calls set_tenant_id — two-layer protection |
| T-06-06 | Information Disclosure | python-jose CVEs | mitigate | python-jose not used; only PyJWT 2.12.1 imported via `import jwt` |
| T-06-07 | Elevation of Privilege | ContextVar not propagating to request handlers | mitigate | set_tenant_id called inside StructlogContextMiddleware.__call__ (not lifespan); each request's asyncio task receives the set value; TenantIsolationError raised if somehow bypassed |
</threat_model>
