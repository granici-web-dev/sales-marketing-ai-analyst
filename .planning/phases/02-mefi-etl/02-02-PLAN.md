## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Information Disclosure | MEFI API response (phone/name/email) | mitigate | structlog config never logs Authorization header; MefiClient logs only page count and rate_limit_remaining — no PII fields |
| T-02-05 | Tampering | MEFI API response JSONB | mitigate | Pydantic v2 validates response before storage; unknown fields ignored via model_config extra='ignore' |
| T-02-06 | DoS | MEFI 429 rate limit | mitigate | RateLimitError raised with Retry-After value; Celery task uses self.retry(countdown=exc.retry_after) — respects server backpressure |
| T-02-07 | Information Disclosure | mefi_api_key in Settings | mitigate | Field is not logged by structlog (not in log context); .env.example has placeholder, not real key; gitleaks pre-commit catches accidental commit |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new runtime packages; respx added to dev-only extras |
