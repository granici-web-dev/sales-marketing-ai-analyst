Unit tests use respx for HTTP mocking and unittest.mock for DB sessions. Integration tests use pytest-asyncio with the existing test PostgreSQL setup (check conftest.py for the async_engine / async_session fixture pattern).

All async test functions use @pytest.mark.asyncio. freezegun.freeze_time used where datetime.now(UTC) is tested.

Unit test behaviors:

test_mefi_client.py:
- test_search_includes_auth_header: respx mock of POST /leads/search → assert "Authorization" in request.headers and request.headers["Authorization"].startswith("Bearer ")
- test_pagination_date_to_fixed: respx mock returning total_pages=3; assert all 3 requests have same date_to value in body
- test_liveness_total_zero_raises: health_check() with respx returning {"meta":{"total":0}} → returns False (not raises)
- test_429_respects_retry_after: respx returns 429 with Retry-After:30 → assert RateLimitError raised with retry_after==30
- test_rate_limit_remaining_sleep: respx returns X-RateLimit-Remaining:5 → assert asyncio.sleep called (patch asyncio.sleep)

test_mefi_repository.py:
- test_bulk_upsert_idempotent: mock session.execute; call bulk_upsert_leads with same external_id twice in rows list → verify ON CONFLICT DO UPDATE (not duplicate insert)
- test_history_emitted_on_status_change: mock SELECT returns {ext_id: (16, "IN PROCES")}; incoming row has status_id=17 → assert detect_and_record_history returns history row with from_status_id=16, to_status_id=17
- test_no_history_when_status_unchanged: mock SELECT returns same status_id → detect_and_record_history returns empty list
- test_custom_field_extraction: row dict with showroom populated from form-cf-14 = "Brașov" → assert row["showroom"] == "Brașov"
- test_bulk_upsert_raises_when_no_tenant_id: row dict missing tenant_id → ValueError raised

test_sync_mefi_leads.py:
- test_sync_run_lifecycle: mock SyncRun, mock MefiClient (health OK, empty data), mock Redis lock acquired; verify SyncRun created with status="running", then updated with status="success"
- test_redis_lock_prevents_duplicate: mock Redis SET returns None (lock already held) → function returns noop dict; logger.info called with "lock_held"
- test_backfill_month_windows: get_12_month_windows(date(2026, 5, 21)) == 12 items, first=(2025-05-01, 2025-05-31), last=(2026-04-01, 2026-04-30)
- test_beat_schedule_configured: celery_app.conf.beat_schedule (or redbeat_schedule) contains "sync_mefi_leads"; schedule time is 04:00
- test_chain_halts_on_failure: if _sync_async raises RuntimeError, the exception propagates through sync_mefi_leads

Integration test behaviors (test_mefi_etl.py):
- test_003_views_exist: after alembic upgrade head, execute "SELECT 1 FROM v_mefi_leads_active LIMIT 0" and "SELECT 1 FROM v_mefi_leads_junk LIMIT 0" → no error (DATA-01)
