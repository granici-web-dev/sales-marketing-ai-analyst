## Color

All values from `frontend/src/app/globals.css` `@theme` block — use CSS variable names, not hex literals.

| Role | CSS Variable | HSL Value | Usage |
|------|-------------|-----------|-------|
| Dominant (60%) | `--color-background` | hsl(0 0% 100%) | Page background, main content area (`bg-white`), modal backgrounds |
| Secondary (30%) | `--color-secondary` | hsl(240 5% 96%) | Sidebar background, topbar background, table row alternating (subtle), card backgrounds, empty state containers |
| Accent (10%) | `--color-accent` | hsl(221 83% 53%) | Active nav item text + left border, primary CTA buttons, chart primary series color, progress/conversion fill bars |
| Destructive | `--color-destructive` | hsl(0 72% 51%) | `avg_time_to_first_touch_minutes > 240` cell background (SALES-02), delete/destructive confirmation buttons, failure notice banner border |
| Foreground | `--color-foreground` | hsl(240 10% 4%) | Body text, table cell text, card headings |
| Muted foreground | `--color-muted-foreground` | hsl(240 4% 46%) | Placeholder text, inactive nav labels, chart axis labels, metadata timestamps |
| Border | `--color-border` | hsl(240 6% 90%) | Card borders, table column separators, sidebar border, topbar border-bottom |

Accent reserved ONLY for:
- Active sidebar nav item (text + left 3px border)
- Primary CTA button fill (Reîmprospătează, Retry where primary action)
- Funnel bar chart primary fill (leads bar — all bars use same accent; conversion arrows use accent color)
- Source breakdown bar chart primary series fill
- Revenue trend line color (LineChart stroke)
- Date range picker selected range highlight
- Focus ring on interactive elements (`--color-ring` = same hsl)

Semantic colors for chart series (multi-series charts — use muted variants from CSS variables or Tailwind zinc scale):
- Primary series: `var(--color-accent)` — hsl(221 83% 53%)
- Secondary series: hsl(221 83% 75%) — lighter tint of accent (30% lighter)
- Tertiary series: `var(--color-muted-foreground)` — hsl(240 4% 46%)
- Additional series: zinc-300 through zinc-600 from Tailwind scale

Severity badge colors (fixed semantic mapping, not from theme variables):
- Critică (critical/high): `bg-red-100 text-red-700 border-red-200`
- Ridicată (high): `bg-orange-100 text-orange-700 border-orange-200`
- Medie (medium): `bg-yellow-100 text-yellow-700 border-yellow-200`

WoW delta badge colors:
- Positive delta (▲+N%): `bg-green-100 text-green-700`
- Negative delta (▼-N%): `bg-red-100 text-red-700`
- Neutral / no prior data: `text-muted-foreground` no badge background

## Interaction Patterns

### Date Range Picker (D-09, D-10, D-22)

- **Desktop (≥ 768px):** Popover trigger button showing formatted date range (e.g. `01.05.2026 – 28.05.2026`). Clicking opens a popover with `react-day-picker` range calendar + preset shortcuts list.
- **Mobile (< 768px):** Bottom sheet modal (full-screen overlay from bottom) containing the same calendar + presets. Triggered by same date button in topbar/page header area.
- **Preset shortcuts** (D-09): `Ultima săptămână` (7d), `Ultima lună` (30d), `Ultimele 90 zile` (90d), `Luna curentă` (calendar month). Each preset is a button that immediately updates URL params and dismisses picker.
- **URL state** (D-10): Selection updates `?from=YYYY-MM-DD&to=YYYY-MM-DD` via `router.push`. Pages read via `useSearchParams()`. Default when params absent: last 30 days (today − 29 → today).
- **Format displayed:** `DD.MM.YYYY – DD.MM.YYYY` in the trigger button label.

### Loading States (D-12)

- One `<Skeleton>` per distinct content block (chart, KPI card, table, insight card).
- Skeleton height matches final rendered content height exactly — prevents layout shift.
- KPI card skeleton: 80px tall (card height), full width of card.
- Chart skeleton: matches `height` prop passed to `<ResponsiveContainer>` — typically 200–280px.
- Table skeleton: 5 rows × table row height (44px each).
- No page-level spinner. No global loading overlay.

### Mobile Sidebar (D-18)

- At < 768px: sidebar is hidden by default (`hidden md:block` or `translate-x-[-240px]`).
- Hamburger button (`Menu` icon from lucide-react, 44px tap target) appears in topbar left area on mobile.
- Click opens full-width slide-over or overlay nav panel from left edge.
- Overlay backdrop: semi-transparent black (`bg-black/40`) closes sidebar on tap.
- All 8 nav items remain visible and accessible in mobile nav.
- Close button (`X` icon, 44px) inside the mobile nav panel at top-right.

### Insight Problem Cards (D-15)

- Collapsed by default. `<Card>` with `cursor-pointer` and `role="button"` on header.
- Header (always visible): severity badge + problem title + estimated_loss_ron formatted as RON string.
- Expanded state: description paragraph + bullet list of `recommended_actions` (action text, owner name, deadline label).
- Collapse/expand: `useState` toggle, animated with CSS `max-height` transition or shadcn `Collapsible`.
- Maximum 3 problem cards per day (business logic: hard max 3 from Phase 5 InsightService).

### Salespeople Table (D-07)

- Sortable columns: click column header to cycle asc → desc → default. Active sort shows `▲` or `▼` icon.
- Default sort: contracts column, descending.
- `avg_time_to_first_touch_minutes` cell: when value > 240, apply `bg-red-100 text-red-700` to that cell only (not the entire row).
- Mobile: `overflow-x-auto` wrapper, sticky first column (`position: sticky; left: 0; bg-white`).
- Revenue column: right-aligned, formatted as RON string. All numeric columns: right-aligned.

### Funnel Visualization (D-04, D-20)

- **Desktop / tablet (≥ 640px):** Horizontal `BarChart` from Recharts, 4 bars side by side (Lead, Vizita, Oferta, Contract). Between each adjacent pair of bars, a conversion percentage label with rightward arrow (e.g. `28% →`). WoW delta badge below each bar count.
- **Mobile (< 640px):** Vertical layout — stages top to bottom. Each stage is a row: stage name, count, and conversion arrow pointing downward (↓) to next stage. Implemented as a custom flex-column layout, NOT as a rotated chart.
- Recharts `ResponsiveContainer width="100%"`. Heights: 200px mobile, 260px desktop.
- On < 640px: hide x-axis gridlines, hide y-axis entirely, show only bar count label above each bar.

### Charts — General (D-06, D-23)

- All charts wrapped in `<ResponsiveContainer width="100%" height={N}>`.
- Height: 200px on mobile (< 640px), 260px on tablet, 280px on desktop. Set via responsive className mapping.
- On < 640px: hide `CartesianGrid`, simplify `XAxis` tick labels (abbreviated month names or date day only), compact `Tooltip`.
- Colors: use CSS variables via recharts `stroke` and `fill` props — `var(--color-accent)` for primary series.
- `legend` shown on desktop only (hidden on < 640px to save vertical space).

### Data Freshness Banner (UI-06)

- Rendered at top of `(dashboard)/layout.tsx` child area, above all page content.
- Reads from a `useQuery` on `GET /api/v1/health/data` (staleTime: 60s, separate from page data).
- When `HealthDataResponse.stale === true`: amber banner (`bg-yellow-50 border-yellow-200 text-yellow-800`).
- When last pipeline run failed: red banner (`bg-red-50 border-red-200 text-red-800`).
- Banner is dismissible per session (localStorage key `freshness_dismissed`). Reappears on next page load.
- One shared `<DataFreshnessBanner>` component in `src/components/`.

## Number & Date Formatting Contract

| Data type | Format | Implementation |
|-----------|--------|----------------|
| Currency / revenue | `1.234,56 RON` | `Intl.NumberFormat('ro-RO', { style: 'currency', currency: 'RON', maximumFractionDigits: 2 })` |
| Large revenue (KPI card display) | `1.234 RON` or `12.345 RON` (no decimals when round) | `maximumFractionDigits: 0` for display-size values |
| Percentage | `28,5%` | `Intl.NumberFormat('ro-RO', { style: 'percent', maximumFractionDigits: 1 })` |
| Integer counts (leads, contracts) | `1.219` (dot as thousands separator) | `Intl.NumberFormat('ro-RO', { style: 'decimal' })` |
| Duration (minutes) | `2h 15min` (> 60min) or `45min` (< 60min) | Custom formatter function `formatDuration(minutes)` |
| Date (short) | `28.05.2026` | `Intl.DateTimeFormat('ro-RO', { day:'2-digit', month:'2-digit', year:'numeric' })` |
| Date (range label) | `01.05.2026 – 28.05.2026` | Two `formatDate` calls joined by ` – ` |
| Timestamp | `28.05.2026, 06:15` | `Intl.DateTimeFormat('ro-RO', { timeZone: 'Europe/Bucharest', day:'2-digit', month:'2-digit', year:'numeric', hour:'2-digit', minute:'2-digit' })` |
| WoW delta badge | `▲ +12%` or `▼ -5%` | Formatted percent with sign + arrow character |

All revenue backend values arrive as decimal strings (DATA-04). Parse with `parseFloat()` before formatting. Do not use `.toFixed()` — use `Intl.NumberFormat` exclusively.

## Constraints & Anti-Patterns

| Anti-Pattern | Correct Approach |
|-------------|-----------------|
| `import { BarChart } from 'recharts'` directly in page | Use shadcn chart wrapper: `import { ChartContainer } from '@/components/ui/chart'` |
| `import ... from '@tremor/react'` | Banned. Zero tremor imports. (UI-08) |
| Hardcoded color hex in JSX (`text-[#2563EB]`) | Use CSS variable: `text-[hsl(var(--accent))]` or Tailwind semantic class |
| Hardcoded Romanian string in JSX | Always `const t = useTranslations(ns); t('key')` |
| `.toFixed(2)` for money | `Intl.NumberFormat('ro-RO', { style: 'currency', currency: 'RON' })` |
| `new Date().toLocaleDateString()` | `Intl.DateTimeFormat('ro-RO', { timeZone: 'Europe/Bucharest', ... })` |
| Empty chart with zero-data axes | Replace with empty state component — do not render empty axes |
| Page-level loading spinner | Skeleton per section — no full-page loader |
| `queryClient` created outside component tree | Create once in `(dashboard)/layout.tsx` with `new QueryClient(config)` inside component |
| Calling backend API directly from Server Component | All dashboard data via TanStack Query hooks in Client Components |
