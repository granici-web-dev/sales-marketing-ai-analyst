## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-7-14 | Spoofing | POST /api/v1/insights/refresh | mitigate | apiClient.post uses credentials: "include"; SameSite=Lax backend cookie (Phase 1) prevents CSRF; rate-limit enforced server-side with Redis SET NX EX 3600 |
| T-7-15 | Tampering | Historical date input value → API URL | mitigate | Input type="date" constrains format to YYYY-MM-DD by browser; additional: validate with new Date(selectedDate) + isNaN check before passing to useInsightsByDate |
| T-7-16 | Tampering | AI-generated text in insight payload | mitigate | payload.summary, problem.title, problem.description rendered as JSX text nodes (React auto-escapes); no dangerouslySetInnerHTML; no eval(); no innerHTML assignments |
| T-7-17 | Info Disclosure | estimated_loss_ron as number type | accept | Business analytics data shown to authenticated users only; auth enforced by apiClient 401 interceptor |
| T-7-18 | Denial of Service | Rate-limit bypass attempt | accept | Backend enforces rate limit with Redis; frontend countdown is UX-only and does not gate security |
