  <action>
    Create backend/app/core/dependencies.py with `from __future__ import annotations` and the following:

    Import: fastapi (Depends, HTTPException), fastapi.security (HTTPBearer, HTTPAuthorizationCredentials), sqlalchemy.ext.asyncio (AsyncSession), uuid (UUID), structlog, app.core.security (verify_token), app.db.deps (get_session), app.schemas.auth (UserOut), app.models.user (User), sqlalchemy (select).

    security = HTTPBearer()

    Async function get_current_user(credentials: HTTPAuthorizationCredentials = Depends(security), session: AsyncSession = Depends(get_session)) -> UserOut:
    1. Call verify_token(credentials.credentials) — if None, raise HTTPException(401, "Invalid or expired token")
    2. Extract user_id = UUID(payload["sub"]) — if KeyError or ValueError, raise HTTPException(401)
    3. Run ORM SELECT on User model: select(User.id, User.email, User.is_active).where(User.id == user_id, User.is_active == True) — specify exact columns, not SELECT *
    4. If no result, raise HTTPException(401, "User not found or inactive")
    5. Return UserOut(id=row.id, email=row.email, is_active=row.is_active)

    Use structlog.get_logger(__name__) for logging but do NOT log user email (PII). Log only user_id on 401 events.

    Note: The existing StructlogContextMiddleware in main.py already sets tenant_id ContextVar from hardcoded settings.sofa_belle_tenant_id on every request. The get_current_user dependency does NOT need to set tenant context — it only validates the JWT and provides user_id for rate-limit keying.
  </action>
