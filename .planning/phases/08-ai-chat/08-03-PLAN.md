<objective>
Deliver the 12-tool registry (D-01..D-04) that backs Claude's Tool Use loop. Each tool is a thin wrapper around an existing Phase 3/5/6 service (D-03 enforced — NO new SQL inside the tool layer, except for the 3 documented thin v_mefi_leads_active text() queries: `get_leads`, `get_loss_reasons`, `get_showroom_performance`). </objective>
