## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client (browser) → SSE endpoint | unauthenticated requests must reject; rate-limit + stream-lock enforced before orchestrator runs |
| FastAPI handler → AsyncAnthropic | per-request instantiation INSIDE event_generator (D-29 + LM-1); errors sanitized before SSE event |
| structlog log lines → ops | no PII; only tenant_id, conversation_id, user_id, tool_name, token counts, durations, error codes |
| stream-lock in Redis → conversation isolation | per-conversation lock prevents two concurrent streams for the same conversation; lock expires after 180s if process crashes |
